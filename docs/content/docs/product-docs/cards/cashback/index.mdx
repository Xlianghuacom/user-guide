## 消费返现

活动期间，客户使用豆星卡、豆盈卡 HK 卡段消费，月度累计净交易额达到门槛，即可享受对应档位的返现比例。

支持卡段：豆星卡、豆盈卡 HK 卡段（558325；54502000；52737560；52737597；54492360；54493747；53240691；53211359；52626363）。

### 消费金额

按客户当月净交易额所在档位确定返点率，返点金额上不封顶。

| 月交易额 （USD） | 返点率 |
| --- | --- |
| 1 万 ≤ X &lt; 5 万 | 0.10% |
| 5 万 ≤ X &lt; 10 万 | 0.15% |
| 10 万 ≤ X &lt; 30 万 | 0.20% |
| 30 万 ≤ X | 0.25% |

## 返现发放规则

返现按当月净交易额计算。月净交易额 = 当月清算交易金额 − 退款 − 拒付，再按该金额所在档位确定返点率。

返点于次月 1 日 00:00 发放至客户钱包账户余额，可用于卡充值或提现。

发生退款或拒付时，对应金额从次月返点中扣回。客户注销时，尚未发放的返点不予补发。
