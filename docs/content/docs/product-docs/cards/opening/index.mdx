# Dowalet 钱包： 豆星卡 & 豆盈卡 开卡教程

<strong>Dowalet Card（VCC）</strong>是 Dowalet 钱包发行的虚拟信用卡，可用于线上广告投放、物流付款、境外平台采购、展会缴费等跨境消费场景。与传统实体卡相比，VCC 在线申请、即时下卡、按卡管理、用完即冻，资金更可控。目前提供「豆盈卡」「豆星卡」两种虚拟卡。

## 一、Dowalet Card VCC - 开卡前准备

开卡前请确认以下事项：

1. 已完成 Dowalet 企业实名认证，账户状态正常；
2. 钱包余额充足（或已知可充值金额），开卡后可按需往卡内充值；
3. 准备好**持卡人**的身份证信息（持卡人可以是法人或员工）：证件正反面照片、姓名、证件号、有效期、生日、手机号、邮箱、账单地址；
4. 开卡用途：用于哪个平台（Amazon / Google / 独立站等）、需要开几张卡。

一个企业账户下可添加多个持卡人、开多张卡，不同卡可绑定不同业务用途，方便对账和费用归属管理。

## 二、Dowalet Card VCC - 开卡流程

登录 Dowalet 工作台，在左侧导航栏点击<strong>「Dowalet Card」</strong>进入卡片管理页。

### 2.1 添加持卡人信息

首次开卡需要先添加持卡人。在卡片管理页右上角点击<strong>「持卡人」</strong>按钮，进入持卡人列表后点击<strong>「新增持卡人」</strong>。

![卡片管理页右上角的持卡人入口](/guide/card/cardholder-entry.jpg)

按表单填写持卡人信息并上传证件：

- **证件类型**：默认"中国大陆居民身份证"；
- **证件照片**：上传身份证人像面、国徽面，系统自动识别填写；
- **个人信息**：姓名、证件号码、证件有效期、生日；
- **联系方式**：手机号、邮箱；
- **账单地址**：邮编 + 详细地址（需与后续刷卡账单一致）。

### 2.2 申请开卡

持卡人添加完成后，回到卡片管理页，点击<strong>「申请开卡」</strong>按钮。

![卡片管理页中的申请开卡按钮](/guide/card/apply-1.jpg)

![暂无可用卡片时的申请开卡入口](/guide/card/apply-2.jpg)

#### 2.2.1 选择卡段与用卡场景

根据用途选择卡类型，并填写申请信息：

- 卡类型：「豆盈卡」「豆星卡」；
- 用卡场景：电商/独立站、订阅服务、广告投放、商务旅行、物流/通信、云服务、其他；
- 交易平台：Amazon、AliExpress、DHgate、Shopify、TEMU；
- 开卡币种：USD；
- 选择卡段：系统展示可选卡段（如 526263，HK 地区）。

![选择豆盈卡、用卡场景与卡段](/guide/card/card-bin.jpg)

![选择豆星卡与用卡场景](/guide/card/card-type.png)

#### 2.2.2 填写开卡信息

- 扣款账户：选择与卡渠道和币种匹配的资金账户——豆星卡从 Dowalet 钱包余额扣款；豆盈卡从已绑定的外部账户（万里汇），充值直接从该账户扣款；
- **持卡人**：选择上一步添加的持卡人；
- **开卡数量**：可一次开多张；
- **卡片备注**：自定义卡片名称（如"Amazon 美国站广告费"），方便后续对账。

![填写扣款账户、持卡人、开卡数量与卡片备注](/guide/card/apply-form.jpg)

确认信息后提交，系统实时开卡。

### 2.3 开卡成功，查看卡片信息

开卡成功后回到卡片管理页，即可看到卡片列表，卡片状态显示"使用中"。

![开卡成功后的卡片列表](/guide/card/card-list.jpg)

#### 2.3.1 查看卡号、有效期、CVV

点击某张卡片的<strong>「查看卡片详情」</strong>，即可看到完整卡号、有效期、CVV、账单地址、持卡人信息等。这些信息用于在 Amazon、Google 等平台绑卡付款。

![查看卡片详情中的卡号、有效期和 CVV](/guide/card/card-detail.jpg)

#### 2.3.2 交易明细、充值与冻结

进入卡片详情后可查看：

- **交易明细**：每笔消费的时间、商户、授权金额、结算金额、手续费、状态；
- **充值**：从钱包余额往卡内充值；
- **冻结 / 解冻**：不用时可临时冻结卡片，防止被盗刷。

![卡片详情中的交易明细、充值与冻结](/guide/card/card-transactions.jpg)

### 2.4 VCC 充值

**豆星卡**：需从 **Dowalet 钱包余额** 充值到卡；

**豆盈卡**：需从已绑定的外部账户（万里汇），充值直接从该账户扣款。

![从钱包余额为卡片充值](/guide/card/topup.jpg)

![豆盈卡扣款账户](/guide/card/topup-account.png)

![确认卡片充值](/guide/card/topup-confirm.jpg)
