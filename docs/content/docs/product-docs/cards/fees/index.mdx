## 用卡须知

### 卡片性质

所有卡片均为<strong>预付费卡</strong>，我们不提供任何信用额度。请在交易前安排卡片充值，并确保卡内有足够余额进行交易。

### 拒付率规则

支付失败比例超过 <strong>20%</strong>，我们将收取授权费用 <strong>2%</strong>（最低 <strong>0.2 USD</strong>）每笔，无论失败还是成功授权。

交易时请确认卡片信息填写正确，以免填写错误造成交易失败。

### 销卡注意事项

如果卡片不再使用，需要在<strong>所有绑定过的相关账户进行解绑后，再进行销卡操作</strong>。

### 测试规范

请合理安排测试卡片和交易的数量。如果发现大量生成 / 取消卡片，且基本不进行任何消费，我们将<strong>关户并不退还任何资金</strong>。

### 退款规则

正常交易不会有太多退款。如果我们发现您使用信用卡在某些平台大量退款（如 Steam），我们将<strong>直接关户，也不退还任何资金</strong>。
