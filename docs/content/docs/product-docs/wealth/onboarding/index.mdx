# 【豆财富】开户流程

<strong>&gt; 适用对象：</strong>首次使用豆财富的企业客户

<strong>&gt; 前置条件：</strong>由公司董事会授权的运营授权人使用手机号注册

<strong>&gt; 整体耗时：</strong>约 1-2 小时（含文件准备）+ 审核等待 1-3 个工作日

## 一、流程总览

| **阶段** | **你需要做什么** |
| --- | --- |
| ① 准备文件 | 扫描/整理 3 份必传文件 |
| ② 在线填写 | 按页面引导填写 4 个模块 |
| ③ 身份验证及文件签署 | 董事/股东/授权人，线上/线下完成身份验证及文件签署 |
| ④ 等待审核 | 等邮件通知结果 |

## 二、注册与登录

1. 登录豆沙包，点击“豆财富”
2. 授权人使用<strong>手机号</strong>注册，设置登录密码
3. 后续登录 = 手机号 + 登录密码 + 短信验证码

### 模块二：人事信息（3 个子页面）

#### （一）联络人与授权人信息

1、授权人类型说明

运营授权人：发出账户指令人士

交易授权人：发出交易指令人士

可以为相同人员，也可以是不同人，但需要与董决文件中的签署指示一致。

系统默认，填写开户申请者为「运营授权签署人」

2、身份证明说明

(1)若授权人国籍为中国大陆，系统默认对客户进行CA认证，后续将向客户预留的邮箱发送"刷脸+传证"链接；若无法进行CA认证，请联系客服

(2)若客户国籍为非中国大陆，需上传身份证件,并进行线下见证

![联络人与授权人信息](/guide/wealth/personnel.jpeg)

#### （二）董事信息与授权签署

1、全部董事和授权人均为中国内地，则可以选择线上生成并签署《董事会决议副本》

2、若存在非内地董事/授权人，则需上传经全体董事签字的《董事会决议副本》

注:决议内容须与公司实际授权安排一致,且与下方「授权签署人」设置匹配(签署人数、签署人姓名、授权范围)一致。

![董事信息与授权签署](/guide/wealth/directors.png)

#### （三）股东/实益拥有人及公司架构信息

- <strong>主要内容：</strong>需提供股东/实际拥有人信息、股东名册（如有）、股权架构信息（如有）、中间层公司文件（如有）
- 若公司存在多层股权架构（控股股东为另一家公司），需上传《股权架构文件》及《中间层公司文件》

![股东、实益拥有人及公司架构信息](/guide/wealth/shareholders.png)

## 六、常见问题

<strong>Q：哪些情况必须联系客服线下开户？</strong>

- 非香港注册公司
- 股东/实益拥有人为美国公民/居民/绿卡持有人
- 资料披露五项声明中任一项与实际不符
- 公司为特定美国税务身份人士
- 复杂多层股权架构且无法在线完整上传材料

<strong>Q：审核被驳回的常见原因？</strong>

- 公司名称/地址与 BR 不一致
- 董事、授权人、股东信息前后矛盾
- 股东名册过期或与填报不符
- 董事会决议与签署授权设置不匹配
- 风险披露声明与实际不符
- 税务或 W-8BENE 信息填写错误

## 七、重要提醒

1. <strong>授权人</strong>：须由公司董事会决策授权的运营授权人注册开户，后续操作均使用该手机号
2. <strong>邮箱</strong>：务必使用可长期使用的公司邮箱，勿用临时邮箱
3. <strong>如实填写</strong>：所有信息须与实际一致，尤其是衍生品认知、风险披露声明、税务信息
4. <strong>多授权人</strong>：如需多人登录操作，请参阅《星企通多授权人操作指引》
5. <strong>语言切换</strong>：系统支持简体/繁体切换，右上角即可操作
