## 交易管理

### 产品列表

当前豆沙包已上架货币基金，可查看“近七日年化收益率”、“近一年收益”。（其他品类敬请期待）

![产品列表](/guide/wealth/manual/image-6.png)

点击相应的产品，可以查看基金详情：

![基金详情](/guide/wealth/manual/image-11.png)

### 买入

点击买入，填写买入金额，输入框下方会显示可用金额和买入费率（货币基金通常不收取买卖费用）。

如若余额不足，可在【资金管理】进行入金。

![买入金额](/guide/wealth/manual/image-1.png)

交易规则处可以查看买入、卖出的Cut-Off 时间，预估确认份额日期、预估查看盈亏日期，预估卖出到账日期。

![交易规则](/guide/wealth/manual/image-20.png)

买入前请先阅读相关协议文件及合适性匹配结果：

![协议文件及合适性匹配](/guide/wealth/manual/image-2.png)

合适性匹配通过则可以认购，若匹配不通过，可以重新测评，进入风测问卷的填写，更新您的风险评级结果。

点击买入进行OPT验证和交易验密，输入对应内容：

![OPT验证](/guide/wealth/manual/image-28.png)

![交易验密](/guide/wealth/manual/image-27.png)

### 卖出

当客户具备某个产品的持仓后，【产品列表】页将会标记出该产品为“持有”，并且“卖出”按钮将会亮起。

![持有与卖出](/guide/wealth/manual/image-30.png)

除此之外，在【我的资产】页的持仓明细，也可以卖出该产品：

![持仓明细卖出](/guide/wealth/manual/image-9.png)

点击“卖出”按钮，触发到赎回页面，当前提供两种卖出方式“份额卖出”和“金额卖出”。

<ol className="manual-steps">
  <li>
    <p>份额卖出</p>
    <img src="/guide/wealth/manual/image-32.png" alt="份额卖出" />
  </li>
  <li>
    <p>金额卖出</p>
    <p className="manual-note">将以最新的净值估算客户可赎回金额，客户可输入自己预期想要收到的金额，系统将会自动估算应赎回的份额数</p>
    <img src="/guide/wealth/manual/image-13.png" alt="金额卖出" />

## 交易记录

<p className="manual-path"><span>菜单路径</span>交易记录</p>

提交订单后，可在订单管理查看订单记录，包括订单状态、下单金额等。待受理状态的订单，在订单cut-off time前可以进行撤单。

![交易记录](/guide/wealth/manual/image-12.png)

## 我的资产

总资产展示按汇率折算的总资产，也可以查看各币种的明细资产。

| 项目 | 说明 |
| --- | --- |
| 总资产 | 包含可用资金+持仓市值+在途资金+冻结金额。 |
| 持仓分布 | 如投资多品类，可用区分品类查看持仓分布 |
| 累计收益 | 即将支持按不同时间区间，不同持仓产品查看收益走势图，每日收益明细等，敬请期待。 |
| 持仓列表 | 展示对应持有产品的持有金额、持有份额、最新净值、累计收益、持有收益、昨日收益等字段。 |

![我的资产](/guide/wealth/manual/image-23.png)

### 风险测评

页面顶部会展示公司名称、证券账号、风测等级、PI标签（如是）。

<div className="is-narrow">

![风险等级标签](/guide/wealth/manual/image-31.png)

</div>

点击风险等级标签进入风险测评首页；

若客户未参与测评，则显示“未测评”，可以点击重新测评，进入风险测评首页；

风险测评有效期为1年，若超过1年未更新，会显示“已过期”，可以点击重新测评，进入风险测评首页：

![风险测评已过期](/guide/wealth/manual/image-18.png)

风险测评首页，点击“开始测评”，开始答题：

![开始测评](/guide/wealth/manual/image-10.png)

<p className="manual-path"><span>菜单路径</span>账户管理 → 我的结单</p>

![我的结单](/guide/wealth/manual/image-19.png)

## 公司行动（基金分红）

若基金发送现金分红，系统会自动派发到证券账户，从除权日开始产生分红记录，可在这里查看分红权益和分红金额，以及实际派发时间。

目前仅支持现金分红类产品。

![基金分红](/guide/wealth/manual/image-24.png)

查看分红详情：

![分红详情](/guide/wealth/manual/image-8.png)

## 账号与安全

系统右上角可点击“账号与安全”修改开户邮箱、重置密码等。

![账号与安全](/guide/wealth/manual/image-22.png)

### 修改手机号

点击右上角个人中心-账号与安全。

### 修改邮箱

暂不支持在线修改，如需修改，请联系客服

<div className="is-narrow">

![修改邮箱](/guide/wealth/manual/image-15.png)

</div>

### 修改交易密码

填写原交易密码，按系统要求填写新交易密码。忘记原密码可进行重置，参见下方&lt;重置交易密码&gt;章节。

![修改交易密码](/guide/wealth/manual/image-4.png)
