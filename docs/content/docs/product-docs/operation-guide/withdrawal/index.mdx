# Dowalet B2B账户：（四）提现

## 提现至银行账户

### 提现流程概览

提现至银行账户需按顺序完成以下步骤：

1. **确认付款信息**：选择付款币种与付款账户
2. **确认收款账户**：选择或新增收款账户
3. **确认提现金额**：输入金额，查看手续费率与到账金额
4. **添加交易附言**（可选）
5. **点击“确认提现”**：提交提现申请
6. **安全验证**：通过手机号或邮箱验证

### 一、提现入口

当收款账户成功接收资金后，即可发起提现，转账至实体银行账户。

**入口：「资金管理」-「提现」**

![资金管理中的提现入口](/guide/withdrawal/entry.png)

### 二、确认付款信息

1. 选择付款币种
2. 选择付款账户

![选择付款币种与付款账户](/guide/withdrawal/payment.png)

### 三、确认收款账户

在收款账户下拉框中选择已录入的 **银行账户** 或 **支付公司账户** 作为收款账户；

若暂无可用收款账户，点击下拉框右侧的 “新增收款账户” 添加收款人：

![选择已录入的银行账户或支付公司账户](/guide/withdrawal/payee-select.png)

![新增收款账户，选择账户类型](/guide/withdrawal/add-account-type.png)

![添加银行账户](/guide/withdrawal/add-bank.png)

![添加支付公司账户](/guide/withdrawal/add-payment-company.png)

### 四、确认提现金额

输入需提现的美金金额后，系统将展示相应的手续费率及到账金额。

![输入提现金额后展示手续费与预计到账金额](/guide/withdrawal/amount.png)

### 五、添加交易附言（可选）

如有需要，可填写交易附言作为转账备注。

### 六、点击“确认提现”

核对信息无误后，点击“确认提现”提交提现申请。

### 七、安全验证

发起提现申请前，需通过“手机号验证”或“邮箱验证”完成安全验证：

![手机号验证](/guide/withdrawal/verify-phone.png)

![邮箱验证](/guide/withdrawal/verify-email.png)

### 八、提现成功

安全验证成功后，即为成功发起提现申请，可在「账单中心」查看交易详情。

![提现申请成功](/guide/withdrawal/success.png)
