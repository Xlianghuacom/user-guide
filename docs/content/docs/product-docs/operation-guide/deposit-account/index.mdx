# Dowalet B2B 账户：（二）开通收款账户

**VA（Virtual Account）虚拟收款账户**是 Dowalet 为外贸企业开立的境外银行账户。开通后即可把银行名、账号、SWIFT Code 等信息发给海外买家，买家直接电汇货款，资金自动归集到 Dowalet 钱包余额。与传统境外银行开户相比，VA 账户全线上申请、无需亲赴网点、无最低存款要求。

## 1. 开通 VA 收款账户

### 1.1 支持范围与开户规则

客户选择目标开户地区后，系统按地区展示对应可选开户银行：

- **欧洲**：可选 Currency Cloud（CC）；
- **美国**：可选 Community Federal Savings Bank（CFSB）；
- **中国香港**：可选 DBS 星展银行、Standard Chartered 渣打银行；
- **中国内地**：可选 微众银行。

### 1.3 收款账户管理

客户完成开户后，可在收款账户列表中查看账户所在国家或地区、银行、账号、状态、账户用途等信息。

| 步骤 | 说明 |
| --- | --- |
| ![收款账户列表](/guide/deposit-account/list-1.png)<br />![账户卡片](/guide/deposit-account/list-2.png)<br />![账户详情](/guide/deposit-account/list-3.png) | **收款账户管理列表**<br />- 点击收款账户卡片右上角的「**详情 >**」按钮，可查看详细的收款账户信息<br />- 可使用该收款账户信息作为收款人<br /><br />**收款账户详情**<br />进入账户详情后，可查看完整银行账户资料，包括银行名称、银行代码、支行名称、收款账号、账户名称、银行地址、SWIFT Code、银行路由号码、可收币种等：<br />- 支持单字段复制，方便按需复制某一项账户信息；<br />- 支持一键复制完整账户信息，适用于向买家、合作伙伴或财务团队提供收款资料；<br />- 账户用途字段用于说明该账户适用场景，例如跨境电商、海外收款或企业跨境收付款等。<br /><br />- 根据需要汇入的币种，切换顶部的汇款币种，查看收款账户及中间行信息。<br />- 中间行用于协助国际汇款完成资金清算。若付款银行的汇款页面要求填写「中间行」「代理行」或「Intermediary/Correspondent Bank」，请填写中间行/代理行信息；如无相关要求，则无需填写。 |

## 2. 钱包多币种资产展示

首页「总资产预估」模块从单一余额展示升级为多币种资产卡片展示。客户可查看已开通币种的总金额、可用余额、待入账金额：

- 当客户拥有多个币种资产时，页面以卡片形式展示，并支持横向查看；
- 系统会将各币种资产按汇率折算为统一的 **USD 总资产**，便于客户判断整体资金规模；
- **待入账金额**可帮助客户识别已有来款但尚未完成入账的资金。
