# Dowalet 钱包：（一）注册登录&认证

## 一、Dowalet 钱包 - 开户准备

Dowalet 钱包支持**中国大陆公司**、**中国香港公司**注册开户。

注册 Dowalet 钱包**无开户费、无年费管理费，也无入账手续费**。

注册只需要准备一个常用手机号或邮箱，即可免费快速完成。企业认证阶段再补充营业执照等材料。提交后系统**实时审核**，通过后即可开通收款。

## 二、Dowalet 钱包 - 注册流程

准备好手机号码或邮箱后，点击 Dowalet 官网的【[**去注册**](https://www.dowalet.com/)】按钮进入注册界面。

![官网去注册入口](/guide/registration/register-entry.png)

### 2.1 注册登录

填写**手机号 / 邮箱**，完成验证并设置登录密码。

![填写手机号或邮箱](/guide/registration/register-1.png)

![设置登录密码](/guide/registration/register-2.png)

### 2.2 账户认证

![账户认证入口](/guide/registration/auth-entry.png)

**账户注册成功**后，登录进入 Dowalet 工作台，按页面提示完成**身份 / 企业认证**。

完成企业实名认证后，即可开通：

- **多币种收款账户**：接收全球主流经济体客户的付款，资金通过当地清算网络到账，一般当天即可到账。
- **平台店铺绑定收款**：绑定 Amazon 店铺后，平台货款可直接归集到 Dowalet 钱包。
- **FastPay 极速回款**：符合条件的卖家可提前回笼平台滞留货款，销售即回款。

![认证后可开通的功能](/guide/registration/features.png)

#### 开始身份认证

| 步骤 | 说明 |
| --- | --- |
| ![上传身份证](/guide/registration/identity-upload.png) | **点击【立即完善】身份认证**。上传身份证正反面，上传后将自动识别并填充证件信息。如果你注册时用**邮箱**作为登录名，此处需要补充验证**手机号**；如果你注册时用**手机号**作为登录名，此处需要补充验证**邮箱**。输入对应联系方式后点击【发送验证码】，填入收到的 6 位验证码即可完成。填写完毕，**点击【提交身份认证资料】**。 |
| ![开始企业认证](/guide/registration/identity-next.png) | **继续【开始企业认证】**。 |

#### 企业认证准备材料

Dowalet 钱包支持中国大陆公司、中国香港公司注册开户。注册时选择的主体类型不同，所需材料也不同。

**中国大陆公司**

| 材料 | 具体要求 | 备注 |
| --- | --- | --- |
| 企业营业执照 | 在有效期内，统一社会信用代码清晰可见，经营范围与实际一致 | 个体户提供个体工商户营业执照 |
| 法人身份证 | 身份证正反面照片、手持身份证照、邮箱、电话号码、住址 | 需在有效期内 |
| 最终受益人（UBO）证件 | 持股 25% 以上股东的身份证正反面 | |

**香港公司**

| 材料 | 具体要求 | 备注 |
| --- | --- | --- |
| 公司注册证书（CI） | 香港公司提供商业登记证（BRC）/ NAR1 周年申报表 | 境外公司提供对应注册文件 |
| 董事身份证明 | 身份证 / 护照 / 港澳通行证正反面 | 需在有效期内 |
| 最终受益人（UBO）证件 | 持股 25% 以上股东护照 / 身份证 | |

#### 大陆公司认证

1. 点击【开始企业认证】，选择【大陆公司】。

| 步骤 | 说明 |
| --- | --- |
| ![上传营业执照](/guide/registration/cn-license.png) | 上传营业执照，上传后将自动识别并填充证件信息。填写【企业名称】和【企业经营地址】。经营地址与注册地址一致时，勾选【与注册地址一致】，系统会自动填写经营地址。填写【企业经营信息】：行业类型、出口国家/地区（选填）、贸易商品类别（可多选）和业务说明。点击【下一步】填写企业关联人信息。 |
| ![填写最终受益人](/guide/registration/cn-ubo.png) | 添加持股 25% 以上的最终受益人（UBO）信息：身份证正反面照片、手持身份证照片、持股比例、邮箱、电话号码、住址。 |
| ![核对并提交](/guide/registration/cn-review.png) | 系统会汇总公司信息、法人信息和最终受益人（UBO）信息。通读一遍后，点击【确认提交】。 |
| ![审核通过](/guide/registration/cn-approved.png) | 系统会发送站内通知告知认证通过。工作台首页「待办事项」中的企业认证卡片消失，收款、提现等功能自动解锁。 |

#### 香港公司认证

1. 点击【开始企业认证】，选择【香港公司】。

| 步骤 | 说明 |
| --- | --- |
| ![上传香港公司文件](/guide/registration/hk-docs.png) | 依次上传「公司注册证书（CI）」「商业登记证（BRC）」「周年申报表（NAR1）」。填写编号与企业名称、成立日期。企业注册地址与经营地址一致时，勾选「与注册地址一致」。填写经营信息：企业行业类型、贸易商品类别、出口国家 / 地区（可多选）和业务说明。全部填完后点击【下一步】，进入关联人信息页。 |
| ![填写关联人](/guide/registration/hk-people.png) | 填写法人、实际控制人、企业重要成员（其他董事 / 股东）。同一人可兼任多个角色。添加持股 25% 以上的最终受益人（UBO）信息：身份证正反面照片、手持身份证照片、持股比例、邮箱、电话号码、住址。 |
| ![核对并提交](/guide/registration/hk-review.png) | 系统会汇总公司信息、法人信息和最终受益人（UBO）信息。通读一遍后，点击【确认提交】。 |
| ![审核通过](/guide/registration/hk-approved.png) | 系统会发送站内通知告知认证通过。工作台首页「待办事项」中的企业认证卡片消失，收款、提现等功能自动解锁。 |
