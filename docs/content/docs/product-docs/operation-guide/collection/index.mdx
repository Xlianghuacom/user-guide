# Dowalet B2B 账户：（三）收款&入账

买家把货款汇到你在 Dowalet 开通的收款账户后，钱包会实时监控每一笔来款，并在交易记录中展示。部分交易根据合规要求需要你补充交易背景资料，资料审核通过后款项才会计入钱包余额；入账后即可继续提现、结汇等操作。

## 一、开通收款账户成功后，一键复制账户信息

收款账户开通成功后，客户可在「收款账户详情」查看完整银行账户资料，包括银行名称、银行代码、支行名称、收款账号、账户名称、银行地址、SWIFT Code、银行路由号码、可收币种等，并支持**一键复制完整账户信息**，适用于客户向买家、合作伙伴或财务团队提供收款资料。

![收款账户详情，可一键复制完整账户信息](/guide/collection/account-copy.png)

## 二、待补充资料的入口

当存在需要补充资料的交易时，有两个入口可以处理：

- **首页待办**：首页会展示待办事项入口，点击即可进入待补充交易；
- **交易记录列表**：从「账单中心 → 交易记录」找到对应交易。交易记录新增操作列，支持**查看详情**、**下载汇款单**和**补充资料**。

![账单中心交易记录，可查看详情并补充材料](/guide/collection/pending-entry.jpg)

## 三、需要补充哪些资料

点击「补充资料」后，弹出汇款单及补充材料上传窗口。材料需完整、清晰、无遮挡，单个文件不超过 10MB，支持 JPG / PNG / PDF 格式。

![汇款单及补充材料上传窗口](/guide/collection/upload-materials.jpg)

| **资料类型** | **说明** |
| --- | --- |
| 汇款单 | 用于证明付款方已发起或完成汇款。 |
| PI | 形式发票，可辅助说明交易背景。 |
| CI | 商业发票，可辅助核验交易真实性和金额。 |
| 合同 | 用于说明交易双方、货物/服务内容及金额。 |
| 物流单据 | 用于补充货物流转与交付信息。 |

## 四、入账流程

1. 款项进入收款账户后，系统根据规则判断该笔交易是否需要补充收款记录资料；
2. 若需要补充资料，首页展示待办，交易记录中也可进入处理；
3. 客户上传相关交易凭证（汇款单 / PI / CI / 合同 / 物流单据）并提交；
4. 资料进入审核，审核通过后款项完成入账，计入钱包可用余额；
5. 入账完成后，客户可按现有钱包能力继续发起提现、结汇、支付供应商等操作。

有些来款需要先补充交易资料，资料补充并审核通过后即可入账；入账后即可进行提现等后续操作。若已有汇款单，可直接下载。
