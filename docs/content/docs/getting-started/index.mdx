## 使用前准备

Dowalet 钱包支持**中国大陆公司**、**中国香港公司**注册开户。注册只需要准备一个常用手机号或邮箱。企业认证阶段再补充营业执照等材料。

注册无开户费、无年费管理费，也无入账手续费。提交认证后系统实时审核，通过后即可开通收款。

## 使用路径

1. 使用手机号或邮箱[注册并登录](/docs/product-docs/operation-guide/registration#二dowalet-钱包---注册流程)。
2. 按主体类型完成[企业认证](/docs/product-docs/operation-guide/registration#企业认证准备材料)。大陆公司和香港公司所需材料不同。
3. [开通收款账户](/docs/product-docs/operation-guide/deposit-account#1-开通-va-收款账户)。开户成功后，在账户详情中复制银行账户信息发给买家。
4. 买家汇款后，在交易记录中查看来款。需要补充资料的交易，从首页待办或交易记录进入处理，审核通过后[入账](/docs/product-docs/operation-guide/collection#四入账流程)。
5. 入账后，从「资金管理」-「提现」把资金[提现到银行账户](/docs/product-docs/operation-guide/withdrawal#一提现入口)。提交前需完成手机号或邮箱验证。
6. 如需虚拟卡，按[开卡教程](/docs/product-docs/cards/opening)申请豆星卡或豆盈卡。收费标准见[费用说明](/docs/product-docs/cards/fees#费用明细表)。
7. 如需开通豆财富，由董事会授权的运营授权人按[开户流程](/docs/product-docs/wealth/onboarding)准备资料并在线填写。
